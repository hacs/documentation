## HACS入門 

 HACS新手？若要開始使用HACS，請若後續步驟操作： 

1. 請檢查是否符合以下要求： [ /docs/use/download/先決條件.md ](    /docs/use/download/先決條件.md    ) 在此之前下載HACS，請先檢查是否符合以下要求。 
2. [ 下載 HACS ](      /docs/use/download/download.md      ).
3. [ 設定 HACS 集成 ](  /docs/use/configuration/basic.md  ).
4. [ 檢查配置選項 ](   /docs/use/configuration/options.md   ).
5. 取得概覽 [ HACS 控制面板 ](    /docs/use/repositories/dashboard.md    ) 並開始使用HACS。
