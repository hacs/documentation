HACS is built into Home Assistant as the Marketplace, starting with Home Assistant 2026.11, and its development continues there. The HACS frontend in [hacs/frontend](https://github.com/hacs/frontend) is no longer developed.

To work on the Marketplace, see the [Home Assistant contributor documentation](https://contributors.home-assistant.io/). The panel lives in [home-assistant/frontend](https://github.com/home-assistant/frontend), in `src/panels/marketplace`.
