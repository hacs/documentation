---

HACS is built into Home Assistant as the Marketplace, starting with Home Assistant 2026.11, and its development continues there. The HACS backend in [hacs/integration](https://github.com/hacs/integration) is no longer developed.

To work on the Marketplace, see the [Home Assistant contributor documentation](https://contributors.home-assistant.io/). The integration lives in [home-assistant/core](https://github.com/home-assistant/core), as `homeassistant/components/marketplace`.
