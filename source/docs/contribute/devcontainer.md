HACS is built into Home Assistant as the Marketplace, starting with Home Assistant 2026.11, and its development continues there. The HACS development environment is no longer maintained.

To work on the Marketplace, see the [Home Assistant contributor documentation](https://contributors.home-assistant.io/), which also explains how to set up a development environment.
