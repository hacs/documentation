The Home Assistant Community Store (HACS) is a custom integration that provides a UI to manage custom elements in [Home Assistant](https://www.home-assistant.io/).

!!! info "HACS is now the Marketplace"
    Starting with Home Assistant 2026.11, HACS is built into Home Assistant as the Marketplace. There is nothing to download anymore. See [HACS and the Marketplace](docs/marketplace.md) for what that means for you.
